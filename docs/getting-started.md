# 快速上手指南 (Getting Started)

本文档面向初次接触 **kujira** 的开发者与使用者，详细说明前置环境准备、双端（桌面端 / 命令行）安装方式、QQ 开放平台机器人凭据申请流程、安全与权限模型规范，以及首次对齐验证。

---

## 1. 前置环境准备

在开始安装前，请确认您的系统满足以下运行时要求：

- **Node.js**：`>= 22.12.0`（受 `better-sqlite3` 原生依赖约束，低于此版本将无法启动）；
- **DeepSeek Harness (DSH)**：`>= 0.2.2-0`（官方全面适配，已验证至 `0.2.2-rc.3+`）；
- **QQ 个人账号**：用于在 QQ 开放平台创建机器人并扫码添加好友；
- **pnpm**：`>= 9.0.0`（*仅从源码编译安装时需要*）。

---

## 2. 安装插件

Kujira 支持两种主流安装途径：**桌面端（GUI）一键安装** 与 **CLI / Web 端安装**。

### 方式一：DSH 桌面端安装（推荐，最简路径）

若您使用的是 DSH 桌面客户端（Desktop）：
1. 启动 DSH 桌面客户端；
2. 点击左下角 **「设置」** → 切换至 **「插件」** 页面；
3. 点击右上角 **「添加插件」** 按钮；
4. 在弹出的包名输入框中直接输入：
   ```text
   kujira
   ```
5. 点击确认，等待安装完成后，在插件列表中勾选启用。

> [!NOTE]
> 桌面版用户无需执行任何终端命令，插件内置已编译产物，安装后即刻在设置面板中呈现 Kujira 配置卡片。

---

### 方式二：从 npm 安装（CLI / Web 端）

若您习惯在终端中运行 DSH 服务并使用 Web UI 进行交互：

```bash
# 推荐：安装到 DSH 的 web profile（隔离运行）
dsh plugin --profile web add kujira

# 或安装到全局默认环境
dsh plugin add kujira
```

---

### 方式三：从源码编译安装（开发者 / 调试模式）

如果您需要基于源码进行二次开发或调试：

> [!IMPORTANT]
> DSH 通过 `package.json` 的 `main`（指向 `dist/index.js`）以及 `dsh.bundle.patch` 加载插件。**在执行 link 链接之前，必须先运行 `pnpm build` 生成产物与预设补丁**。

```bash
# 1. 克隆代码库
git clone https://github.com/Jiangsubei/kujira.git
cd Kujira

# 2. 安装依赖并执行全套构建（包含预设同步、tsc 编译与客户端 WebUI 面板构建）
pnpm install
pnpm build

# 3. 将本地开发目录 link 链接到 DSH
dsh plugin --profile web add link:.
```

## 3. QQ 开放平台机器人创建与凭据获取

本项目基于腾讯官方合规 OpenAPI 与正向 WebSocket 协议，无需搭建或维护任何第三方协议端（如 NapCat / SnowLuma），所有鉴权直接通过官方凭据完成。

### 步骤详细拆解

1. 打开浏览器访问 [QQ 开放平台官网 (https://q.qq.com/)](https://q.qq.com/)，使用您的个人 QQ 账号扫码登录；
2. 登录成功后，在左侧导航栏点击 **「机器人」**；
3. 点击 **「去创建」** 或 **「管理我的机器人」** → 点击 **「创建机器人」**；
4. 填写机器人的基础信息（如机器人名称、头像与简单简介等），确认创建；
5. 进入该机器人的管理详情页：
   - 在 **「基础信息」** 选项卡中，复制 **机器人 ID (AppID)**；
   - 在 **「开发管理」** 或 **「密钥管理」** 选项卡中，点击生成或复制 **机器人密钥 (AppSecret)**。

## 4. 权限模型与安全隔离（核心红线）

在开始使用前，请务必充分理解 Kujira 的权限与交互设计哲学：

> [!CAUTION]
> **默认 1 对 1 开箱即用，多好友场景请务必开启隔离**
> 
> 1. **创建者默认独占**：在 QQ 开放平台创建该机器人的开发者，**默认即为机器人管理员，且默认可直接通过手机 QQ 添加该机器人为好友**，无需在后台额外配置白名单。
> 2. **未配置名单时默认全开放**：默认假设为 1 对 1 私人助手场景；当 `admins` 为空且 `privacy_tools_enabled` 关闭时，好友拥有完整工具、审批权限与全部斜杠命令控制权。
> 3. **多好友防隐私泄露配置**：如果您希望让其他好友体验机器人，请在 WebUI **「更多配置」** 设置中配置：
>    - **管理员名单 (`admins`)**：先用管理员账号给机器人发一条消息，再点 `+` 从脱敏列表中选中自己（支持多选）。配置后仅管理员可审批敏感工具及执行 `/权限`、`/模型 -默认`、`/思考 -默认`，其余日常命令与会话内 `/模型`、`/思考` 仍可供好友使用；
>    - **隔离可能泄露隐私的工具 (`privacy_tools_enabled`)**：勾选开启后默认对所有单聊隔离 Shell、文件读写、目录、环境依赖与技能加载工具，可在下方将自己加入**白名单**（或切换**黑名单**精准隔离指定好友）；
>    - **保存即热生效**：配置保存后对所有活跃会话立即热生效，无需重启或新建会话。

### 关于让其他好友体验的说明
如果您需要让身边的朋友添加机器人体验：
- 登录 QQ 开放平台机器人详情页，进入 **「开发设置」** → **「可添加机器人为好友的开发体验用户」** 添加好友 QQ 号；
- 在 DSH **「更多配置」** 设置中配置好 **管理员名单** 并开启 **隔离可能泄露隐私的工具**（并将自己加入白名单），防止宿主机文件与环境隐私泄露。

## 5. DSH 端凭据配置与热连

获取到 `AppID` 和 `AppSecret` 密钥后，将其录入 DSH：

1. **进入 Kujira 设置面板**：
   - **桌面端**：进入「设置」→「插件」，点击 `kujira` 的配置图标；
   - **Web 端**：执行 `dsh --profile web` 启动服务，浏览器打开 `http://127.0.0.1:3080/` 并进入 `kujira` 设置卡片；
2. **填写核心凭据**：
   - 切换到 **「常规 (Connection)」** 分区；
   - 在 **AppID** 输入框中填入机器人 ID；
   - 在 **密钥 (AppSecret)** 输入框中填入生成的密钥；
3. **点击保存**：
   - 凭据将由 DSH 核心安全服务 `ctx.credentials` 自动写入持久化加密凭据库（`$DSH_HOME/.credentials.yaml`），前端遵循只写安全协议，不回显明文；
   - 插件将自动触发网关热连接，握手连接腾讯 QQ 开放平台官方 WebSocket 网关。

> [!TIP]
> **开箱即用**：除了 AppID 和密钥两项必填凭据外，其余 28 项参数（管理员与隐私工具隔离、回复时钟、记忆预算、黑话、表情包等）均自带开箱即用的默认值，初次启动无需繁琐调参！

## 6. 首次对齐验证与日常交互

配置保存且网关连接成功后，即可开始首次对话验证：

### 第一步：添加机器人好友
1. 在 QQ 开放平台的机器人后台查看机器人的测试二维码或 QQ 号；
2. 使用您创建机器人的手机 QQ 扫码或搜索添加机器人好友；
3. 点击通过，进入单聊窗口。

### 第二步：执行指令测试
在 QQ 单聊窗口中发送中文斜杠命令：
```text
/状态
```
机器人将以原生 Markdown 排版返回当前系统状态（包含当前加载的模型版本、思考档位、网关连接延迟与运行时信息），证明整条链路完全通畅。

### 第三步：体验拟人化对话与动态时钟
- 尝试连续发送多条短消息，感受 **仿生动态时钟** 的聚合等待（25% 温和折减与防打字饥饿）；
- 尝试发送一张表情包或图片，观察机器人如何结合上下文理解图片意图；
- 尝试告诉机器人：“*我叫小明，我平时喜欢玩黑神话悟空*”，机器人将在回复完毕后，在后台顺手提炼持久化记忆！

## 7. 常见首跑问题与排查提示

| 现象 | 可能原因 | 解决方案 |
|---|---|---|
| 发送消息后机器人无响应 | AppID 或 AppSecret 填错，网关鉴权失败 | 检查 WebUI 中的凭据状态，确认复制时未夹带空格并重新保存 |
| 无法添加机器人为好友 | 使用了非创建者 QQ 号且未加白名单 | 在开放平台「开发设置」中将当前 QQ 号加入「开发体验用户」 |
| 发送斜杠命令无回执 | 会话处于排队或模型未就绪 | 查看 DSH 控制台日志，确认大模型推理服务（LLM Service）配置正常 |
| 撤回消息失败 | 超过 QQ 官方 2 分钟时限 | QQ 开放平台严格限制仅可撤回 120 秒内发出的消息，超时会自动拦截 |

如需了解完整的系统架构、时钟算法数学模型或高级配置项，请继续参阅 [系统架构与设计哲学 (docs/architecture.md)](architecture.md) 与 [运行时配置全景参考 (docs/configuration.md)](configuration.md)。
