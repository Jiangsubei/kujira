## 1. 交付概况与核心收益

本次重构彻底废除了原有的全局固定周期时钟（自由时钟），全面升级为**基于 Peer 独立的事件驱动仿生时序引擎**：

1. **去全局固定轮询**：每位单聊好友维护独立的会话状态机，时序器仅由入站消息、Agent 轮次结束（`turn/end`）与仿生潜水闹钟纯事件驱动；
2. **温和折减 + 下限锁定（彻底防饥饿）**：
   - 周期内每收到一条新入站消息，当前剩余等待时间温和折减 25%（`remaining * 0.75`）；
   - 一旦折减触碰配置的下限 $T_{min}$，目标唤醒时刻**永久锁定在下限**，后续连发新消息只入池、不再推迟、不再重算定时器，保障了在用户连发打字打断插话的拟人节奏；
3. **双层活跃度与动量体系**：
   - 微观时效：计算入站与上一轮 Bot 出站时差 $\Delta t_{turn}$（秒级接话 vs 异步离席）；
   - 宏观动量：纯函数回溯 SQLite 最近 $X$ 轮已完成 Agent 循环的时延与消息密度，平滑单次偶发抖动；
4. **两组区间 + 分段偏好 + 秒回开关（极简直观）**：
   - 聚合区间：`aggregation_min_seconds`（默认 10s）与 `aggregation_max_seconds`（默认 60s）；
   - 潜水区间：`idle_reply_min_mins`（默认 30m）与 `idle_reply_max_mins`（默认 120m）；
   - 互动偏好：`[ 热情 | 均衡 | 冷淡 ]`（分段按钮单选 Segmented Control，对应幂律采样偏置 $p = 2.0 / 1.0 / 0.5$）；
   - 概率秒回：`instant_reply_enabled` 独立开关，开启后高活跃度下允许突破下限（0~2s 内极速触发）。
5. **旧配置彻底清除与物理自愈**：
   - 彻底移除了 `aggregation_interval_mins` 与 `idle_reply_timeout_mins`；
   - 物理自愈引擎自动将残留旧键作为 staleKey 外科手术式清洗，有效 Volatile 键精准收敛为 **23 项**。
